# 🛍️ TrendyCart — Myntra Deals & Loot Aggregator

**TrendyCart** is a curated fashion-deal aggregator that surfaces real-time price drops, loot deals, flash sales, and exclusive coupons from Myntra.

---

### ✨ Key Features

- ⚡ **Real-Time Loot Alerts:** Instant updates on sudden price drops, glitch sales, and limited-time discounts.
- 👗 **Curated Fashion Feeds:** Categorized deals across Menswear, Womenswear, Footwear, Accessories, and Beauty.
- 🏷️ **Coupon & Promo Tracking:** Auto-aggregated discount codes and bank offer breakdowns.
- 🔗 **Direct Affiliate Links:** Fast and seamless redirect to Myntra product checkouts.
